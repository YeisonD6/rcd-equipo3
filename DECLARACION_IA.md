# Declaración de uso de IA

Se utilizó Codex con el MCP de Cisco Packet Tracer para interpretar el enunciado y la rúbrica, construir la topología, aplicar configuraciones, consultar el estado vivo, guardar el proyecto y preparar documentación.

Instrucciones suministradas: topología del Equipo 3, direccionamiento IPv4/IPv6, VLAN, EIGRP, OSPFv2/OSPFv3, túnel, IPsec, ACL, SNMP, servicios, Tracker y criterios de aceptación.

Validación aplicada: inventario vivo, inspección de enlaces y puertos, lectura de VLAN, extracción de startup-config, auditoría de seguridad, direcciones SLAAC, captura del canvas, guardado del .pkt y pruebas de ping donde el MCP devolvió resultados.

Se verificaron DNS A/AAAA, lectura HTTP/HTTPS desde clientes, conexiones TCP permitidas/bloqueadas, mensajes del Tracker, ACK, alerta de actividad y permanencia superior a 60 segundos. Se capturaron decisiones por capa de Simulation Mode y contadores ESP. La prueba GET/SET de MIB Browser permanece pendiente.
